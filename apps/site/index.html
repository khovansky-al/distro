Welcome to Linux running natively in your browser!

There's no x86_64/RISC-V emulation going on here, instead this is a port of the kernel to WebAssembly.

We've got a patched version of the Linux kernel running, complete with virtio devices, memory isolation, and multi-core support. For the userspace, we've ported BusyBox and Musl, and much more.

If this sounds interesting, you can check out the source at github.com/tombl/linux (the kernel) and github.com/tombl/distro (the userspace and this site).

To give the guest raw TCP access, add a URL-encoded WebSocket endpoint as the relay query parameter, for example ?relay=wss%3A%2F%2Frelay.example.net%2F. Without it, the demo retains its fetch-based HTTP adapter. Approved inbound mappings can be requested repeatedly with publish=RELAY_PORT:GUEST_PORT, for example &publish=12345:80. The guest service must bind its Ethernet address or 0.0.0.0, not only 127.0.0.1. Published ports carry raw TCP and bypass reverse-proxy authentication, so the service must protect itself when exposed beyond loopback.
